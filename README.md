## Overview

MobiHealth is a healthcare web application focused on delivering accessible health resources, child development information, vaccination guidance, and digital healthcare experiences through an intuitive interface.

## Features

- **Healthcare & Child Care** — Accessible health resources and child development information.
- **Vaccination** — Interactive vaccination guides, vaccine categories, and detailed vaccine information.
- **Paediatrician & Hospitals** — Dedicated sections for healthcare discovery.
- **Responsive UI** — Interfaces designed for different screen sizes.
- **Healthcare Dashboard** — Dedicated frontend experiences for patient and clinical workflows.
- **Scalable Architecture** — Structured to support future backend services and AI-powered healthcare features.

## Tech Stack

| Technology | Purpose |
|---|---|
| React + TypeScript | Frontend application |
| Vite | Development and build tooling |
| React Router | Client-side navigation |
| CSS | Styling and responsive layouts |
| NestJS *(planned)* | Backend API |
| PostgreSQL + Prisma *(planned)* | Data storage and database access |

## Getting Started

**Prerequisites:** Node.js and npm.

```bash
# Clone the repository
git clone https://github.com/maheshchopra/mobihealth-next-gen.git

# Navigate to the project
cd mobihealth-next-gen

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open the local URL displayed in your terminal.
